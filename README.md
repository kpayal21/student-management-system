# student-management-system


A simple Student Management System
developed using C++.

## Features
- Add student records
- Store student details
- Calculate total marks
- Calculate percentage
- Assign grades
- Display student records

## Technologies Used
- C++
- STL
- VS Code

## Concepts Used
- Structures
- Vectors
- Functions
- Conditional statements
- Loops

## How to Run

Compile using:

g++ student-management.cpp -o student

Run using:

./student
